## Commit authorship

- NEVER add `Co-Authored-By`, `Co-authored-by`, or any attribution line crediting an LLM model or AI agent in any commit message.
- NEVER add code comments, docstrings, or any inline attribution that credits an LLM model or AI agent.
- All commits must appear solely under the human developer's git identity. Do not modify `user.name` or `user.email` git config.
